## Linux Do visual reference

The in-game monitor currently uses an original, low-resolution forum mockup
inspired by the general layout of a Discourse-style technical community. It
does not reproduce real Linux Do posts, usernames, avatars, or screenshots.
The `LINUX DO` name is used only in this internal prototype. Brand/screenshot
permission must be confirmed before a public commercial release.
